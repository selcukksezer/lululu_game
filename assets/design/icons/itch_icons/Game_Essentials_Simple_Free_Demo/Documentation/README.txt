Game Essentials Simple: Universal UI Icons - Free Demo

Static game UI PNG artwork with simplified colorful, rounded shapes and thick
navy outlines. Categories cover navigation, common actions, currencies,
shopping, rewards, progression, inventory, player stats, social features,
world navigation, time, audio, settings and alerts.

Contents
- 20 unique icons across 20 categories, with 1 image per category.
- Transparent 256 x 256 pixel PNGs in 8-bit RGBA format, with no upscaling.
- 40 PNG copies across two folder views, plus 3 documents: 43 files total.

This Free Demo contains one approved icon from each of the 20 categories. These are the same PNG images included in the full pack, not alternate variants.

Folder guide
Game_Essentials_Simple_Free_Demo/
  All_Icons/: all 20 icons together.
  Icons_By_Category/: the same images in 20 numbered category folders.
  Documentation/: README.txt, PREVIEW.txt and LICENSE.txt.

The two icon folders contain byte-identical duplicate views of the same
20 unique icons. Choose either view for import; use one copy per icon.
See PREVIEW.txt for the exact category folders and selected PNG filenames.

Basic usage
1. Open the pack folder. Extract it first if supplied as a ZIP.
2. Read Documentation/LICENSE.txt before using the images.
3. Choose PNGs from All_Icons or Icons_By_Category and import them through
   your game engine or design tool's image import workflow.
4. Preserve transparency and proportions when resizing or displaying images.
5. Assign the images to your own menus, counters, item slots or controls.

These are static images, not functional buttons or code. Implement actions,
labels and any hover, pressed or disabled states in your own project.
The visual style suits Roblox-style interfaces; import settings and integration
are the developer's responsibility and depend on the chosen engine and project.
