Game Essentials Simple: Universal UI Icons - Free Demo

20 unique transparent 256 x 256 pixel, 8-bit RGBA PNG icons across 20 categories.
Simplified colorful, rounded UI graphics with navy outlines for navigation,
actions, currency counters, shops, rewards, inventories, stats and notifications.

This Free Demo contains one approved icon from each of the 20 categories. These are the same PNG images included in the full pack, not alternate variants.
